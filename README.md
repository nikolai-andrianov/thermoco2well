# THERMOCO2WELL

This repository contains the source for [https://thermoco2well.dk](https://thermoco2well.dk), and
the MRST source developed in the project (see [`mrst/`](mrst/)).

# Running the website locally

1. Git clone the repo to a local folder.
2. Open  `cmd ` or  `Terminal ` in a the cloned  `thermoco2well ` folder, and type  `python app.py `.
3. Open  `http://127.0.0.1:8050/ ` in a browser.

# Dependencies

Backend is run with [GNU Octave](https://octave.org).
